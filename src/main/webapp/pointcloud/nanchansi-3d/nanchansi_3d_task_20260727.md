# 南禅寺大佛殿三维交互模型 - 任务记录

## 目标
创建山西五台南禅寺大佛殿的Three.js三维交互HTML页面。

## 完成内容

## 技术实现
- Three.js ES Modules + importmap (three@0.160.0)
- OrbitControls 交互控制（拖拽旋转、缩放、阻尼）
- PCFSoftShadowMap 软阴影 + ACESFilmicToneMapping 色调映射
- 射线投射（Raycaster）实现悬停高亮与点击检测

## 3D模型结构（8个可点击部分）
1. **大佛殿主体** - 不可见包围盒，整体信息
2. **歇山顶与鸱尾** - 前后坡屋面、正脊、戗脊、鸱尾装饰、瓦垄
3. **斗拱（五铺作双抄）** - 栌斗、两跳华拱、散斗、泥道拱、令拱、齐心斗
4. **檐柱与侧脚升起** - 12根檐柱（侧脚内倾+角柱升起）、柱础
5. **梁架结构（四椽栿通搭）** - 四椽栿、平梁、叉手、脊檩、椽条、唐代题记
6. **唐代彩塑（华严三圣）** - 释迦牟尼佛、文殊（骑狮）、普贤（骑象）、弟子、供养菩萨
7. **佛坛与月台** - 台基、阶条石、月台、踏步、佛坛
8. **唐代题记（梁下墨书）** - 梁下墨书平面

## 交互功能
- **自动旋转**：场景整体旋转
- **拆解视图**：各结构层Y轴方向分离展示
- **重置视角**：相机回到初始位置
- **底部图层选择器**：7个图层切换按钮（全部/屋顶/斗拱/檐柱/梁架/彩塑/台基）
- **悬停Tooltip**：鼠标悬停显示部件名称
- **点击信息面板**：右侧滑入面板，含标签、标题、正文、元数据标签
- **加载动画**：禅字印章脉冲动画

## 设计风格
- 中式古典美学：暖木质色调（#8b5e3c）+ 唐代风格
- 字体：Ma Shan Zheng（标题）+ Noto Serif SC（正文）
- 配色：暗色背景 + 金色(#c9a84c)强调 + 朱红(#9e3b2e)装饰
- 装饰元素：左下角"建中三年"印章、纹理叠加层、雾效
