- 纯CSS + 原生JS，无框架

## 模型结构
基于佛光寺东大殿真实建筑数据构建了8个可交互部分：

| 部分 | 说明 |
|------|------|
| 东大殿主体 | 面阔七间(34m)、进深四间(17.66m)、坐东朝西 |
| 斗拱铺作 | 七铺作双杪双下昂，高3.4m、宽4.7m，柱高1/2 |
| 庑殿顶与鸱吻 | 单檐庑殿顶，举高1/4.77，坡度平缓 |
| 柱网金厢斗底槽 | 内外两圈柱，侧脚升起，无普拍枋 |
| 佛坛唐代彩塑 | 35尊彩塑，主佛+胁侍菩萨+弟子等 |
| 唐代壁画 | 拱眼壁间壁画 |
| 台基与经幢 | 石砌台基、经幢纪年 |
| 唐代题记 | 梁下墨书"佛殿主女弟子宁公遇" |

## 交互功能
1. **鼠标拖拽** — OrbitControls旋转视角
2. **滚轮缩放** — 距离12~80单位
3. **点击部件** — 弹出信息面板（含历史、建筑、文化详情）
4. **悬停高亮** — emissive发光+tooltip显示部件名
5. **自动旋转** — 右侧按钮切换
6. **拆解视图** — 各部分按偏移量分离展示
7. **重置视角** — 平滑动画回到默认视角
8. **底部图层选择器** — 9个图层按钮，可单独显示各部分
9. **加载动画** — 旋转环+进度条

## 视觉设计
- 暖木质色调（#9a7b4a系列）+ 唐代风格
- 暗色背景 + 雾效营造氛围
- 四角装饰边框
- 环境粒子飘动效果
- 远山轮廓模拟五台山环境
- 殿内暖色点光源
- ACES色调映射

## 模型建筑学特征
- 柱子使用LatheGeometry实现卷杀效果
- 檐柱侧脚（角柱内倾）与升起（角柱增高）
- 斗拱分层构建：栌斗→泥道拱→华拱→下昂→令拱→齐心斗→擦檐枋
- 庑殿顶使用自定义BufferGeometry构建四面坡
- 鸱吻用ConeGeometry
- 佛塑含莲花座、背光、肉髻等细节
