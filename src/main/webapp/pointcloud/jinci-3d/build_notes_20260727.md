# 晋祠圣母殿 3D 交互模型 — 构建记录

## 任务目标
创建太原晋祠圣母殿的三维交互HTML页面，使用Three.js ES Modules + importmap。

## 产出文件
- `/Users/nxhuang/.qclaw/workspace/jinci-3d/index.html` (单文件, ~66KB, 2222行)

## 技术栈
- Three.js r0.160.0 (ES Modules + importmap)
- 纯HTML/CSS/JS单文件，无构建步骤
- OrbitControls 实现交互
- 自定义BufferGeometry构建歇山顶屋顶

## 实现功能
1. **8个可点击构件**：台基月台、鱼沼飞梁、副阶周匝、殿身主体、屋顶鸱吻、木雕盘龙柱、宋代彩塑、难老泉
2. **信息面板**：点击后从左侧滑入，含标签、描述、关键数据网格、文化阐释
3. **拆解视图**：右侧按钮开启，底部滑块控制各构件按方向分离
4. **自动旋转**：OrbitControls autoRotate
5. **重置视角**：平滑动画回到初始视角
6. **底部图层选择器**：9个按钮（全景+8构件），可隔离显示
7. **悬停tooltip**：鼠标悬停高亮构件+浮动提示
8. **加载动画**：进度条+百分比模拟加载
9. **罗盘指示器**：左下角方位（坐西朝东）
10. **难老泉动态效果**：气泡浮动+水面透明度变化
11. **环境元素**：古柏树（含周柏造型）、雾效

## 视觉设计
- 中式古典暖木质色调配色方案
- CSS变量管理色板：wood-light/mid/dark/darker、roof-tile、stone、accent-red/gold
- 毛玻璃面板效果(backdrop-filter)
- 宋体字体栈
- 响应式适配移动端
