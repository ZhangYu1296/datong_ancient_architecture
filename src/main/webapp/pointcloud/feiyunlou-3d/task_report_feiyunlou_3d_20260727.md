## 功能清单

### ✅ 三维建筑模型
- 三层四檐主体结构（底层+二层+三层，各带屋檐）
- 十字歇山顶（四面歇山面+正脊+鸱吻+宝顶+翼角翘起）
- 345组斗拱（底层、二层、三层各环绕斗拱阵列+四角斗拱）
- 底层四面抱厦（四面各出小抱厦，带小檐和歇山顶）
- 二层三层平座栏杆（木制花格栏杆环绕）
- 琉璃装饰（黄绿两色琉璃瓦条+屋脊琉璃）
- 内部五层结构（半透明显示5层楼板+内柱+通天柱+楼梯暗示）
- 东岳庙庭院（石台基+台阶+6棵古柏+围墙）

### ✅ 交互功能
1. **可点击8个部分** — 弹出信息面板（tag/title/body/stats）
   - 飞云楼主体、斗拱、十字歇山顶、底层抱厦、平座栏杆、琉璃装饰、内部五层结构、东岳庙庭院
2. **拆解视图** — 点击按钮后屋顶/琉璃上浮、各层间距拉开、内部结构透明度增加
3. **自动旋转** — OrbitControls.autoRotate，速度0.8
4. **重置视角** — 缓动动画回到初始相机位置(28,18,32)
5. **底部图层选择器** — 6个图层按钮（全景/十字歇山顶/三层四檐/斗拱/抱厦基座/内部五层），切换构件可见性
6. **悬停高亮tooltip** — 鼠标悬停时emissive高亮+显示构件名称tooltip
7. **加载动画** — 毛笔字"飛雲樓"标题+进度条+百分比

## 架构说明
- `makeDougong()` — 生成单组斗拱（斗+拱+昂）
- `makeXieshanRoof()` — 生成十字歇山顶
- `makeEaveLayer()` — 生成屋檐层（含斗拱环）
- `makeFloor()` — 生成楼层（柱+梁+楼板+可选栏杆）
- `makeBaosha()` — 生成四面抱厦
- `makeInnerStructure()` — 生成内部五层（半透明）
- `makeCourtyard()` — 生成庭院环境
- `partsGroups` — 按类型分组管理所有构件
- `partInfo` — 8个构件的详细信息数据
- `selectPart()` — 点击选中+高亮+显示面板
- `setLayerVisibility()` — 图层显示/隐藏控制
